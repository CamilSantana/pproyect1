Registro Académico

Programa hecho con Java Swing donde se escriben los datos de un estudiante (nombre, matrícula y carrera) 
y sus notas de prácticas, parciales, asignaciones y examen final. Al darle a "Calcular Resultado" suma todo 
y dice si el estudiante quedó APROBADO (60 puntos o más) o REPROBADO.

Si falta algún dato, o una nota tiene letras o se pasa del máximo, muestra un mensaje de error.
